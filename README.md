# 小张起灵 PWA

[在线使用](https://xiaozhang-pwa.pages.dev/) · [MIT 代码许可](LICENSE) · [第三方素材说明](THIRD_PARTY_NOTICES.md)

独立于已完成的 PC 端和 Android 工程、持续更新的 Cloudflare Pages PWA。移动端只开发 Android。当前恢复工程包含：

- 可安装 PWA 外壳、Service Worker、响应式聊天界面和 IndexedDB 本地数据
- 用户自配 OpenAI-compatible Chat Completions，支持 SSE、普通 JSON 和无 Key 离线回应
- 张起灵角色提示词、立绘、拖动桌宠、姿态切换、摸摸头、投喂、抱抱和亲密度事件
- Pointer Events 拖动、点击/拖动分离、惯性、边缘反弹和减少动态效果适配
- 私聊、可持久化本地群聊和逐角色分轮回复
- 本地朋友圈：文字动态、原图上传缓存、点赞和评论
- 生图结果以 Blob 持久化，并把原始描述作为普通文本事件写入聊天历史
- 自定义表情包导入、名称、描述、标签编辑与搜索，支持用户发送或由张起灵发送实际图片
- 输入表情包名称、标签或描述的末词时显示联想条，可直接发送已有图片
- 礼物、虚拟账单、分类、备注、筛选和编辑；金额均为虚拟记录
- 模型可按隐藏结构化动作协议触发角色送礼、虚拟转账或主动发起语音/视频通话；动作经本地校验后才执行，不连接真实支付
- 角色资料、用户偏好、关系状态、世界书、补充提示词和记忆搜索/编辑
- 本地 JSON 备份与恢复，默认不导出 API Key
- 私密日记：离线保存、搜索、编辑、删除，并包含在本地备份中；不会自动注入聊天上下文
- 独立相册：汇总聊天、朋友圈和生图中的本地图片，支持搜索和历史恢复
- 查岗与受控互动卡片：生成明确标注为虚构的角色手机痕迹，卡片按钮会写回聊天事件
- 可选主动陪伴：页面保持打开时按冷却时间发送本地预设消息，系统挂起时不保证后台执行
- 浏览器系统朗读、麦克风录音消息本地缓存、可选 MiniMax / ElevenLabs 云端 TTS
- 一起听：本地音频持久化、用户自定义头像、播放列表与进度控制；可选 GPT `input_audio` 或 Gemini 原生音频分析，摘要缓存后交给当前聊天模型生成张起灵反馈
- 仿微信消息布局：左右头像、长按消息查看朗读/复制/删除操作；顶部功能收纳进菜单，摸头/投喂/抱抱集中显示在角色记录中

## 本地开发

```powershell
git clone https://github.com/ashlia53760-07/xiaozhang-pwa.git
cd xiaozhang-pwa
npm ci
npm run dev
```

生产构建：

```powershell
npm run build
```

将 `dist` 发布到 Cloudflare Pages。API Key 只写入浏览器本地 IndexedDB，不进入源码或构建产物。直接请求服务商时，需要服务商允许浏览器 CORS；`worker/` 目前只提供健康检查，避免做成任意 URL 代理。

建议使用 Node.js 22 LTS 或更新的 LTS 版本。`npm test` 执行 TypeScript、生产构建和源码冒烟检查。浏览器回归使用 Playwright 和本机 Chrome；先启动 `npm run preview -- --host 127.0.0.1 --port 4177 --strictPort`，再运行 `npm run test:themes` 或 `npm run test:plus-menu`。其他专项测试的地址配置见对应脚本和 `docs/`。

开源范围为此网页版工程，PC 和 Android 工程不包含在本仓库。`.local-review/`、`artifacts/`、依赖、构建产物及本地环境配置不纳入版本控制。聊天、心情、经期和 API Key 保存在使用者浏览器本地，不是仓库示例数据。

参考过的「没心机」仓库是 AGPL-3.0；本项目只参考其公开的模块组织和交互思路，没有复制其源码，PWA 源码独立维护。

洛可可主题参考 [qimingjiu/Trianon](https://github.com/qimingjiu/Trianon)，使用其 CC0 装饰素材及 OFL 字体；许可与来源保存在 `public/themes/rococo/`。青铜夜札使用原创 SVG 舆图。主题交接与验证见 [docs/themes-20261103.md](docs/themes-20261103.md)。

洛可可与青铜夜札的装饰卡片仅在聊天记录开头出现，随记录向上滚动；心动约会的场景设定也置于剧场记录开头，滑回顶部可重读。它们不会占用固定阅读区域，也不会作为聊天消息存储。生产预览启动后运行 `npm run test:scrolling-intros`，检查滚动、刷新、消息重绘和手机/桌面布局。

线下和心动约会的楼层支持长按（电脑右键或焦点处按 Shift+F10）打开操作菜单。可以编辑自己或角色的这一条文字；「回到这里重新开始」保留选中层及之前的内容，将后续楼层移出当前剧情，回退前自动创建关系档案保存节点。不会自动调用模型，保留在用户输入层时可用底部菜单的「重新生成」接回角色回应。操作说明与验证见 [docs/scene-floors.md](docs/scene-floors.md)。

本目录不读取或修改原工程的用户数据。DeepSeek、Kimi 和 OpenAI 预设使用 OpenAI-compatible 接口，实际模型名仍可在设置中修改。聊天 API 只收到文本历史：生图描述和表情包文本元数据会进入上下文，图片 Blob 不会发送给不支持图像输入的聊天 API。朋友圈原图、聊天媒体、录音和 TTS 音频均保存在本机 IndexedDB；浏览器清理站点数据会删除这些本地内容。

GPT 音频分析要求所选模型和服务商支持 Chat Completions `input_audio` 内容格式；普通文本模型及不支持该格式的兼容 API 无法读取音频。Gemini 使用原生 `inlineData` 音频请求。网络/CORS/模型权限错误会显示失败，不会伪造分析结果。音频只在用户开启自动分析后上传一次，后续只用本地文字摘要。
