# 日历模块交接（2026-11-03）

网页版原「日记」入口改为「日历」。保留原 IndexedDB v4 和 diary store，不迁移或清空旧数据。新增关系档案内的 `calendar-data` KV，包含每日心情/经期/备注、共享开关、导入日程和更新后的休班表。新数据进入完整备份及关系档案的保存节点、导出、导入、分支；重新开档时为空。修改前源码检查点在 `.local-review/calendar-module-20261103-120400`。

## 已实现行为

- 真实公历月历、农历日期及春节/元宵/端午/七夕/中秋/重阳/除夕等节日；前后月、月份跳转、回到今天。
- 随包提供 2025、2026 年中国大陆官方放假与调休表，分别标「休」「班」。其他年份不复用旧年调休，可点击联网更新。更新读取公开 holiday-cn 数据并要求存在国务院文件来源；没有有效安排或断网时保留当前数据。
- 按天保存、编辑、清除心情、经期状态（开始/经期中/结束/非经期）及备注。月历显示记录与经期标记。不自动预测周期。
- 旧日记无日期时优先取夜记 automationKey，再取创建时间，不取修改时间。可编辑日记日期；原有张起灵夜记仍在晚八点后打开时尝试生成，保留原幂等 claim、失败释放与重试逻辑。编辑夜记不会改成用户署名。
- 默认开启日历共享，界面有可关闭的明确开关。近七天已记录事实及最多三篇用户日记用于私聊、通话、线下和约会，也供张起灵写夜记。未来/过期记录不注入；不根据旧经期断言当日状态。群聊与朋友圈的生成入口没有新增这份上下文。关闭共享不删除已经发生的聊天。
- 生日簿包含 16 位角色、用户生日和原提醒开关；自定义日期优先于收录日期。日历展示及原生日互动使用同一个日期解析器。二月二十九日只在闰年触发。提醒在打开网站/进入联系人时触发，不是系统后台推送。
- `.ics` 导入支持普通全天事件、跨日全天事件和仅 `FREQ=YEARLY` 的年度重复事件。含具体时间、其他重复规则、例外日期的事件明确计数跳过，避免误标日期。支持重复导入去重和删除，文件上限 1 MB、总日程上限 2000 条。导入日程只在日历展示，不自动发送聊天。
