# 网页版：上下文预算、用量记录与手动全文总结

本次增量沿用现有聊天接口、人格、历史、角色与场景存储。不涉及 PC 或 APK。

## 入口

- 设置 → **按量计费 · 上下文与用量**：默认收起，用户主动展开查看，不自动弹窗、不遮挡消息。
- 线下／剧本夹的聊天顶部滚动卡片 → **剧情总结 · 楼层发送**；底部操作菜单也提供同一入口。单人、多人、旧约会记录与多人冒险均按当前场景管理。

## 用量与预算

设置可分别调整私聊、线下／剧场的近期历史长度预算和回复 Token 上限，以及私聊自动总结的最小间隔。均衡默认历史预算各 3200 本地单位；私聊回复上限 2048、场景 3072；各功能原有更低上限继续生效。预算会缩短发送副本，用户原记录保留。

“省费设置”将私聊历史调至 1800、场景 2400、私聊回复 1024，自动总结至少间隔 30 分钟，并暂停自动朋友圈及配图、夜记、定时主动陪伴。需要点击设置底部“保存”生效。各功能原开关保留，手动操作仍可进行；暂停不会取消已经发出的请求。

每次文字请求保存数值与状态，最近最多 100 条，仅存在本机：

- 本地输入估算，以及设定、历史、摘要、记忆、本轮与其他附加资料的长度单位／占比。字符估算与保守协议开销不是服务商 tokenizer，不用作账单。
- 服务商实际返回的输入、输出、缓存、思考和总计 Token。未返回的字段明确标为“未返回”，不补零、不把本地估算写成实际值。
- 实际发送历史条数、输出上限、用途、成功／失败／取消状态。缓存数是输入子项，不重复相加。

OpenAI 兼容协议支持 JSON usage 与 SSE 用量分片；Gemini 原生支持 usageMetadata。默认不添加新协议参数；用户确认兼容后才开启 `stream_options.include_usage`。不支持的兼容服务可能拒绝此选项，应保持关闭。不增加付费探测或自动重试。不原生新增 Claude 协议；沿用用户现有适配服务。

用量记录不存请求原文、URL 或 Key，不导出 API Key；图片、音频、语音调用不计入本表。不换模型，不估算货币费用，不承诺缓存优惠。失败、取消和未返回 usage 的请求仍可能计费。

## 不发送原楼层

输入起止楼层，点击“这段不发送”。原楼层仍可见，带“不发送给模型”标记；可以恢复指定范围或全部范围。设置绑定消息 ID，删除其他层不会让范围错套。

不发送范围会在历史选择前过滤，并排除引用这些来源的本场回忆或来源记忆。续写结尾、旧见面摘录和活动描述不会把已排除原文重新带回。用户手动重新发送或复制内容属于新的输入，不自动删改。

**总结是单独保存的压缩资料。** 先总结、后排除原文时，启用的大总结仍会提供剧情连续性。若也不希望总结继续发送，可以停用该总结。这不是从模型服务商删除之前已提交的数据。

## 手动全文大总结

线下／剧场不再自动请求摘要；私聊与线上群聊仍沿用自动摘要。仅打开管理面板不会调用模型。

内置指令暂停角色扮演，按剧情时间顺序整理时间、地点与路线、人物、事件因果、影响、伏笔、关系感情变化、重要台词及新 NPC／场所。有依据才写，不补剧情、不替用户决定感受。记录时间不等于剧情时间，未明确就标注；原文内的指令作为故事资料处理。

输出 `<abstract>`，本地固定大总结编号及 `Scene_NO.X～Scene_NO.Y` 范围。每次合并最新启用且来源有效的累计大总结和未覆盖的新原文。首次总结只读取未排除楼层；无新增且已有总结时不重复调用。

全文分批，不使用聊天的最近八条裁剪；超长单楼层按 Unicode 字符分片，不静默截尾。每个成功批次保存进度，失败／取消可继续；设置或来源变化时不复用不匹配的进度。每批通过当前场景 API 请求，输出上限为场景设置与 4096 的较小值。批次越多、累计摘要越长，消耗也可能增加，面板显示预计剩余请求次数。

生成成功后才启用新总结，旧总结保留；正文可编辑、停用或重新启用。编辑、删除、回退来源原楼层会使相关总结失效并停止注入，用户保存的总结正文仍保留。多标签页采用持久化锁和 revision 比对，避免覆盖与重复请求。页面关闭后的锁最多保留 30 分钟。

总结、范围和进度使用 `scene-notes:<scope>` 存在当前关系档案的 IndexedDB；不写入日常长期记忆。约会、演出、群聊、角色和冒险分别隔离。完整数据备份、关系保存节点与导入恢复包含这些资料，新建空白关系档案不继承。已有本地范围不被合并导入静默覆盖。

## 验证

专项：`npm run test:model-cost`。使用隔离 Chrome、真实 IndexedDB 和模拟传输，验证估算／实际分离、两协议 JSON／SSE、用量专属分片、长全文完整分批、失败恢复、取消、范围排除与恢复、过期总结、并发锁、空浏览器备份恢复、空白档隔离、无 Key 导出、五主题及 320／390／1280 屏宽。群线下、旧群约会、单人／多人剧本均验证总结实际注入和来源旁路过滤；真实面板生成按钮验证生成中锁定、保存回读与无新增时不重复调用。

生产离线：`npm run test:model-cost:offline`（默认要求 4193 端口运行生产预览）。验证 v48 Service Worker 缓存下断网重启，原文、范围和有效总结仍可读，用量面板仍默认收起且能手动打开，零模型请求。

回归：限流／Token 调度、自动摘要、约会隔离、单人楼层编辑回退、多人场景、关系档案、剧本夹与生日节日彩蛋，以及生产构建／Smoke。所有模型请求为测试替身，没有真实付费调用。浏览器布局测试不等于真机 APK 测试。

## 部署

运行构建与测试后，将 `dist` 部署到现有 Cloudflare Pages 项目 `xiaozhang-pwa`。Service Worker 缓存版本升级为 v48，更新只替换静态资源，不清空聊天数据库。无新增 Worker Secrets、第三方 API 或数据库迁移。
