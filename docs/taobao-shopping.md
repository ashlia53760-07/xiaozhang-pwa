# 淘宝选品功能已撤下

状态：2026-11-04，根据用户要求暂停本功能，当前发布版不再提供选品入口。

- 已移除选品面板、商品卡片组件、商品查询服务、商品工具调用和专用配置。
- 普通私聊与群聊发送链接按原有聊天流程处理，不自动查询商品。
- 原有聊天、群聊、日历、线下和逐场独立的心动约会继续保留。
- 未清空 IndexedDB。旧聊天的商品 metadata 保留原样；休眠 shopping-workspace 资料只作为已有存档数据保留，不被读取到角色回复中，仍可随关系档案节点保存。
- 没有启用真实商品数据源、上传用户淘宝登录信息或配置商品服务密钥。

撤下前的独立模块代码记录在 Git 提交 `39cf669`，原始接入记录在 `6065a0a`，不随当前版本运行。后续是否恢复另行决定。

验证命令：`npm test`、`npm run test:feature-removal`、`npm run test:date-isolation`、`npm run test:group-scenes`、`npm run test:chat-limits`。
