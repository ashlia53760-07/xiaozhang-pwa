# 剧本夹（2026-11-04）

## 入口与使用

「功能 → 剧本夹」替代原心动约会入口。私聊和群聊打开的是同一个关系档案内的剧本夹；多人演出无需创建群聊。

- 我的剧本：填写名称、最多 6000 字指令、氛围文风，选择单人（一位角色）或多人（2–16 位角色）。可填写仅本剧使用的称呼、人物关系与创作要求，使用原有预设和上传背景。
- 保存、另存、编辑和删除只影响指令模板；开演前也会保存。内容不变时不递增版本。
- 每次开演创建全新演出，冻结当时的剧本、人物名单和关系安排。改版、换人重演或删除模板不改变旧场。
- 返回剧本夹保留当前进度；「演出存档」可继续、查看或提取当场指令为新剧本。结束后仍可查看或接着演。
- 旧单人及群聊约会原文保留在演出存档，可继续，也可把指令收为剧本。旧场继续使用原有的人物设定来源与模型路径。

## 叙事和隔离

新单人及多人演出复用已有统一场景叙事器、模型请求、限流、长按编辑、回退、停止与重新生成。每轮只生成一则连续叙事，按情节分配人物笔墨。

新单人优先沿用所选角色的联系人 API 配置；多人优先共享聊天配置，未配置时尝试出演者现有配置。没有模型时保留已保存剧本和输入，不生成模拟角色剧情。

新演出只读取原著人物底稿、本剧明确填写的设定、本场记录及本场回忆。不读取日常私聊、群聊背景/世界书、线上线下经历、私人日历或其他演出。人物临时关系不写回联系人；「保存到本场回忆」不写共同/长期记忆。编辑、删除、回退来源后，过时回忆不会再进入模型。

群聊转线下保持原有日常衔接和本群公开资料；没有改成独立副本。剧本夹的新演出不在 `groups` 中创建辅助群。

## 存储与兼容

- `script-library` KV：可复用模板。逐模板修订号事务防止多页面覆盖，过期保存或删除失败时保留编辑文字。
- 既有 `date-sessions`：新演出增加 `scriptSnapshot`，其余沿用现有结构。每场使用自己的摘要与回忆，回退不终止其他演出。不升级或清空 IndexedDB。
- 原有背景图继续使用媒体库。整机备份包含模板、演出、快照、本场回忆，以及模板和快照引用的背景；关系档案节点/分支同样保留。
- 独立「导出剧本」只导出模板文字与角色选择，不包含演出、背景图片或服务配置。导入采用字段白名单，最多 5 MB/2000 个模板；同编号保留本地版本。带图片和正文请使用整机备份。
- 新演出进入已有时间线，点击可回到对应场次；设定卡仍随消息上滚。剧名在顶部缩略，全文显示在设定卡。

## 验证

`npm test`、`npm run test:script-library`、`npm run test:date-isolation`、`npm run test:group-scenes`、`npm run test:archives`。

浏览器测试使用独立临时 Chrome、合成 IndexedDB 和拦截的模型回复，不读取用户资料、不消费付费接口。覆盖单/多人、模板修订与删除后续演、记忆隔离、旧场、模型失败/停止、并发、媒体快照、导入导出和备份恢复，以及五主题 320/390/1280 宽度。页面截图不是 Android 真机验收，模拟回复不代表真实模型文笔验收。

本轮不含分幕、秘密揭露、分支树、纸条彩蛋或公开剧本社区。
