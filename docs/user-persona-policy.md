# 用户身份规则

用户扮演对象固定为女性原创人物；留空不要求重新填写性别，仍按女性处理。已有角色的本名、别名、性转身份不能用作用户身份或对用户的称呼。正常讨论原作角色和与其建立关系允许，例如“我是吴邪的朋友”。

- 角色资料保存、全角色同步、朋友圈昵称、群资料和剧本保存会校验用户身份。
- 私聊、通话、连续线下、剧本夹、群聊及多人剧场在发请求前再次校验；导入或旧存档也经过请求前校验。记录不会因此被删除。
- 群与独立剧场只校验其本身公开资料，不额外读取私聊人设，保持原有记忆隔离。
- 朋友圈、日记、陪玩请求同样携带固定身份规则。没有新增审核模型或额外审核请求。
- 明确冲突在本地中断，不调用模型；模型识别到其他语义冲突时返回专用标记，应用停止回复，不保存角色消息或执行互动。

实现：`src/user-persona-policy.ts` 集中维护规则、常见角色本名/别名和显式身份声明校验，`src/api.ts` 统一接入 OpenAI 兼容及 Gemini 原生请求。输入量估算包含新增规则。

边界：本地名单与文本匹配不是对任意自然语言的完备判定，复杂隐喻、未收录别名等仍依赖所配置模型遵守固定规则；不能宣称任意第三方模型绝对不会误判或漏判。

验证：启动 Vite 后运行 `npm run test:user-persona-policy`，可通过 `PERSONA_TEST_URL` 指定地址。使用隔离浏览器、合成存档及拦截接口，无真实模型费用。
