# 群聊线下与多人约会

## 多人叙事

1. 从已有群聊打开「功能 → 线下」或「功能 → 心动约会」。每个群独立保存进度，返回聊天、刷新后可以继续。
2. 线下填写地点、时间、环境。约会可选择预设，或填写最长 6000 字的自定义剧本、人物安排和文风。
3. 每次落笔由一个模型合写一则完整的多人场景，人物动作、对白、环境与停顿穿插，按情节分配主次。不要求人人说话，不按成员名单轮流报幕，不继承线上群聊的自然、指定或全员接话规则。点名可以突出该人物，但不会把场景拆成独立回复。
4. 同行者沿用开场时的成员名单；禁用成员停止参与，新加入的成员从下次开场起参与。展开「同行人数 · 多人叙事」可查看在场人物。模型获得各人的原著性格、时间线、关系边界和本群公开补充，不代写用户的选择、感受或台词。
5. 优先使用设置中的共享聊天模型；共享模型未配置时，使用在场成员中第一份已配置的联系人模型。整则场景使用这一份配置，保持原有 API 协议适配与限流。短场景一轮一次剧情请求；长历史达到阈值时可能额外请求一次摘要。
6. 「停止续写」保留已保存的楼层。生成失败后可重新生成；重写已有叙事时，成功后才替换原文。续写失败后的重试追加新场景，不覆盖上一则成功叙事。
7. 楼层长按／右键可编辑或回到这里重新开始；回退前保存关系档案节点。底部菜单支持重新生成、续写、多选删除，楼层操作本身不自动请求模型。

## 阅读

- 线下现场卡与约会剧本卡都位于消息记录的最顶部，随记录一起滚动。滚到最新剧情后卡片离开视野，滚回顶部可重读完整设定。
- 同行说明即使展开也随卡片一起上滚；重新渲染、编辑或多选后保持一张卡片。
- 新的多人叙事作为一则完整楼层呈现，不挂在某一位人物的头像下。旧版逐人楼层保留原作者和原文，不合并、不删除；后续自然接入新的叙事方式。

## 衔接与归属

- 沿用本群公开背景、世界书、公告和成员公开关系作为人物设定；只有线下读取启用的共同记忆，不读取私聊人设补充、历史、私人日历或其他群资料。
- 线下每轮参考本群近期线上内容，结束时把见面摘要写入原群，方便线上接续；跨次见面保留现场楼层。
- 所有心动约会（群聊与私聊）每场独立：不读取日常聊天、线下、其他约会、共同／长期记忆或私人日历，旧 openingContext 不再使用。手动「保存到本场回忆」只写入该 DateSession.localMemories，不写回群或私聊。原先可识别的约会回忆保留在旧存档中，但从日常、共同记忆上下文排除；无法识别出处的手工复制内容不能自动归类。已存在的旧剧情原文不回写或删除。
- 摘要缓存按每群线下和每场约会隔离；近期原文和用户更正优先。本场回忆保存来源签名，编辑、删除或回退涉及的来源后不再引用旧回忆；随整机备份恢复。

## 数据与兼容

- 群线下继续保存在关系档案数据库 `kv` 中的 `group-life:<groupId>`，群约会继续保存在 `date-sessions`，不修改数据库版本。
- 新叙事楼层在原 `ChatMessage.metadata` 中保存 `sceneNarrative` 与 `sceneMemberIds`，沿用备份、恢复、编辑和回退结构。旧的 `replyMode`、`selectedMemberIds` 字段可以保留在存档中，但不参与剧场生成。
- 原有修订号事务拒绝其他页面的过期写入。未改变普通群聊的接话规则、私聊模型流程或 PC／Android 工程。
- 整机备份继续包含 `groupLifeScenes` 与原 `dateSessions`；不导出 API Key。

## 验证

生产构建后启动 `npm run preview -- --host 127.0.0.1 --port 4184 --strictPort`，运行 `npm run test:group-scenes`。可用 `GROUP_SCENE_TEST_URL` 指向其他预览或正式站。

测试在独立 Chrome 临时上下文中使用合成 IndexedDB 和拦截的模拟模型，验证一轮一则叙事、三人／十六人资料传入、公开资料隔离、点名不拆场景、旧存档续写、失败／停止／重写、长历史摘要、楼层编辑回退、并发与备份，以及五主题下 320×568、390×844、1280×900 的阅读空间与卡片滚动。`npm run test:date-isolation` 另外验证私聊和群聊各两场约会的双向隔离、日常聊天与日历正向对照、旧 openingContext 与旧共享回忆不进入请求、本场保存不写共享库及来源编辑后的回忆失效。测试不会调用付费模型，也未作 Android 真机或真实模型文笔验收。

回归命令：`npm run test:scene-floors`、`npm run test:groups`、`npm run test:scrolling-intros`、`npm test`。截图和报告只写入被 Git 忽略的 `.local-review/`。
