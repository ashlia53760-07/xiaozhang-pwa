# 线下与约会楼层操作

在线下见面、心动约会的文字楼层长按约半秒，可打开楼层菜单。电脑支持右键；键盘聚焦楼层后按菜单键或 Shift+F10。拖动滚动、轻点和多选删除模式不会误触菜单。正在生成回复时暂不允许编辑或回退。

- **编辑这一条**：多行编辑自己的落笔或角色回应，只替换选中层的内容。保留 ID、发言者、时间和其他元数据，后续楼层保留。不自动重新生成后续剧情。取消、空白输入或保存失败不丢失原文；写入失败时编辑框仍保留输入。
- **回到这里重新开始**：再次确认后，保留这一层及之前的内容，后续层不再用于当前剧情。原完整进度先保存到设置中的关系档案节点，可恢复为独立分支；不自动调用模型。若停在自己的输入层，可用原有底部菜单的「重新生成」接回角色回复。

同一线下阅读器中的多人冒险也沿用这些操作。回退只调整对应现场的楼层和当前活动提示；角色资料、其他联系人的会话、其他约会、礼物和结算不会倒退。手动保存的长期回忆仍是独立记录；关联到被修改消息 ID 的记忆会标记待核对。

## 实现与兼容

`src/scene-floors.ts` 负责长按、滚动取消、键盘入口、多行编辑和二次确认；`src/scene-floors.css` 为局部模态样式，复用主题色。

`storage.sceneFloors` / `storage.changeSceneFloor` 按角色、约会 ID 或冒险 ID 定位。保存时在一个 IndexedDB 事务中核对当前楼层快照，拒绝覆盖另一页面已修改的文字；只清理相应场景的摘要和租约，递增会话版本。线下后续层软隐藏并关联保存节点，约会和冒险切断消息数组；完整旧数组可从保存节点恢复。冒险数据 `fieldwork-data` 加入关系档案白名单，确保其回退节点包含原调查记录。

未改变数据库版本、旧楼层结构、场景补充提示、角色设定或备份格式。编辑内容仍通过文本转义展示。Service Worker 为 shell-v38。

## 验证

生产预览 `http://127.0.0.1:4177` 启动后运行 `npm run test:scene-floors`。线上或其他预览使用环境变量 `SCENE_FLOOR_TEST_URL`。测试使用独立 Chrome context、合成 IndexedDB 和模拟 API，未读取真实用户数据、未调用付费模型。

覆盖：真实触屏长按、右键、键盘；用户和角色多行编辑；取消、空白、转义、时间/元数据保留；另一页面编辑冲突；配额错误事务回滚并保留输入；回退确认/取消、完整节点导出与恢复为分支；后续请求使用修改后的内容且不带被回退的剧情；生成中锁定、滚动和多选不误触；五款主题的 320/390/1280 宽度；刷新持久化、其他会话隔离、多角色冒险与调查资料保留。截图和结果保存到忽略上传的 `.local-review/scene-floors/`。

另通过原有 `scripts/scene-ui.test.mjs`：旧约会、自定义背景、多轮交流、失败重试、备份和恢复。`npm run test:scrolling-intros` 检查上次补丁的随记录滚动行为，`npm test` 检查 TypeScript、生产构建和源码冒烟。浏览器尺寸模拟不等同于 Android 真机验收。
